## v0.3.1 — close gaps from this release (~1-2 weeks)

Small, well-scoped items that close known issues. Priority order.

### Coherence

1. **Resolve `workspace-monitor` packaging incoherence.** C source lives at `device/lib/tui/workspace-monitor/` (3 files, 45 KB), TROUBLESHOOTING.md tells users to put `/opt/uconsole/bin/workspace-monitor` in their labwc autostart, and `framework.py:421-426` reads `$XDG_RUNTIME_DIR/labwc-active-workspace` (the file the daemon would write) — but **no build step exists**. Functionally degrades to "no workspace info" rather than crashing. Pick one:
   - (a) Wire into `packaging/build-deb.sh` (deps: `libwayland-client`, `wayland-scanner`), ship binary to `/opt/uconsole/bin/`
   - (b) Document as user-build-from-source, add Makefile target
   - (c) `git rm` the source + framework hook + TROUBLESHOOTING reference

2. **Move shipped specs/plans to `docs/internal/done/`.** 4 of 5 specs and 2 of 3 plans in `docs/internal/{specs,plans}/` describe shipped features:
   - SHIPPED: `2026-05-02-aio-v2-tui-and-radio-switcher.md` (plan + spec), `ADSB_BASEMAP_PLAN.md`, `2026-04-19-wardrive-wigle-explorer.md`, `2026-04-22-mimiclaw-wifi-and-esp32-tui-refactor.md`, `2026-04-24-esp32-detect-hang-fix-design.md`, `2026-04-25-tui-framework-refactor-design.md`
   - STAYS: `2026-04-21-uconsole-suspend-to-ram.md` (deferred awaiting kernel rebuild)

3. **Close GitHub issues #45-#49 with release-tag links.** These shipped in v0.3.0 (security hardening, set -euo pipefail on PMU scripts, trackball timeouts) but are still listed as open on the issue tracker.

### Security

4. **Drop default webdash password `clockwork`.** Currently seeded by `packaging/postinst:71`. Options:
   - Print a one-time random password to stdout at install
   - Disable webdash until first-login setup completes
   - Refuse to start the service while password matches install-time default

5. **Invalidate other sessions on `/api/change-password`.** One-line fix in `device/webdash/app.py:251` — call `_active_sessions.clear()` then re-mint the caller's token.

6. **Add confirm step to TUI process kill** (`device/lib/tui/processes.py:85-91`). Today Enter immediately sends SIGTERM — too easy to kill systemd or NetworkManager via gamepad fat-finger.

7. **WiFi password via stdin, not argv** in `device/webdash/app.py` `nmcli` call. Local-user `ps` disclosure during the connection window.

### OSS front door

8. **Seed GitHub Discussions.** Pin a welcome thread for v0.3.0 ("what this is, how to try it") + create Q&A / Show & Tell / Ideas categories. Empty Discussions tab reads as "ghost town."

9. **Add `.github/ISSUE_TEMPLATE/config.yml`** with `blank_issues_enabled: false` and `contact_links` pointing to Discussions (general questions) and SECURITY.md (vuln reports).

### Observability

10. **Add `lastBackupAt` to `push-status.sh` payload.** Read `git -C ~/pkg log -1 --format=%ct` and push it. Removes the branch-coupling dependency for the indicator the operator looks at most. ~10 lines of bash. Threshold the dashboard tile to red at >36h.

11. **Wire `device/scripts/util/backup-restore-smoke.sh` into `ci.yml`.** Script's own header says "Wire into CI" — never happened. Free guard against the regression class it was written to catch.

## v0.4 — bigger lifts

### Code health

12. **Split `device/lib/tui/marauder.py`** along feature seams. 3199 LOC + zero behavior tests = single biggest fragility risk in the repo. Suggested split: `marauder/wardrive.py` (385), `marauder/ble.py` (288), `marauder/wifi_scan.py` (236), `marauder/portal.py` (135), `marauder/sniffers.py` (123), `marauder/_osm.py` (232). Effort: 1-2 days.

13. **Tighten `tests/test_lint.py`** to fail on `imported but unused` (F401). Then one mechanical cleanup pass over the 69 hits (mostly one `from tui.framework import (...)` boilerplate block copy-pasted into `radio.py`, `adsb.py`, `watchdogs.py`, `config_ui.py`). Effort: 2 hours total.

14. **Adopt `ruff` baseline.** Drop in `pyproject.toml` with permissive `[tool.ruff]` enabling F401 + F841 + F541 + bare-except + mutable-default. Auto-fixable, replaces the manual pyflakes runner. Effort: 2 hours.

15. **Behavior tests** for the v0.2-era big untested modules: `games.py` (1439 LOC), `mimiclaw.py` (1000), `monitor.py` (698). Curses can be mocked the same way `test_telegram.py` already does. Effort: 1 day each.

16. **Type hints rollout.** Today only 4 of 30 TUI modules use them (`launcher`, `marauder`, `tools`, `telegram`). Pick 3-5 high-impact ones per release rather than a big-bang. Effort: ongoing.

### Documentation

17. **First 5 Minutes / Getting Started guide.** Walk the 6-step `uconsole setup` wizard with screenshots: hardware detect → CPU/voltage tuning → webdash password → cloud link → SSL → systemd timers. Currently users hit the wizard with no doc to reference. Highest-leverage missing doc.

18. **Hardware compatibility matrix.** Single table: feature × required hardware. Meshtastic needs SX1262 (AIO board with LoRa), ADS-B needs RTL-SDR, FM needs RTL-SDR, MimiClaw needs external ESP32, antenna monitor needs MT7921 (AC1200), WiFi Radio Mode picker needs CM5 + AC1200, AIO v2 panel falls back to v1-only script. Users with partial hardware can't predict what works today.

19. **Per-feature setup guides** for Meshtastic, ADS-B (readsb feeder), Telegram (Telethon auth), MimiClaw (where to buy + flash), ESP32 hub (firmware sources, what "Bruce" is). Five features name-dropped in README with no how-to. Can share a `docs/HARDWARE-FEATURES.md`.

20. **Marauder + wardrive user workflow.** Internal spec is design-only and excluded from user docs. Needed: firmware flashing pointer, scan/select/attack workflow, GPS-tag requirement, capture file format, OSM/Overpass overlay setup, legal/ethical disclaimer.

21. **`docs/API.md` completeness.** Missing routes today: `/api/raw`, `/api/settings/regenerate-token`, `/api/github/*`, `/api/auth/[...nextauth]`. Also: clarify it's cloud-only and link to a new webdash API doc (the `device/webdash/docs/ecosystem.md` shape).

22. **Uninstall + upgrade guides.** Neither exists. `apt remove` vs `apt purge` blast radius, what `uconsole unlink` does, CM4→CM5 / AIO v1→v2 / v0.2→v0.3 migration paths.

### Observability

23. **External uptime ping** for `https://uconsole.cloud/apt/dists/stable/Release`. UptimeRobot free tier or Better Uptime. Today a bad Vercel deploy silently 404s `apt update` and the only signal is a user filing an issue.

24. **Crash counter in telemetry.** `push-status.sh` includes `crash_count_this_boot` + `last_crash_at` from `~/crash.log`. Dashboard tile turns red when non-zero. Otherwise crashes are only visible by opening the TUI panel in-hand.

25. **Write `docs/internal/RUNBOOK.md`.** Coverage: GPG key recovery (1Password copy location, re-import flow), 1Password service-account token rotation, GitHub PAT rotation, "APT repo returned 404 — what now", "backup hasn't run in 3 days — what now", "Upstash hit quota — what now". 80 lines would be a big upgrade.

### Cloud / security

26. **Rate-limit `/api/device/code/confirm` and `/api/settings/regenerate-token`.** Both authed today; this is defense-in-depth against a compromised session.

27. **Frontend `dependabot.yml` or Renovate.** Was clean before publish; will drift again.

28. **Studio (Sanity) dep updates.** 12 high, 22 moderate currently. Not user-facing (admin UI run locally) but keeps the audit dashboard noisy.
