# Code of Conduct

This project adopts the **[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)** as its code of conduct.

In short: be respectful, be kind, give people the benefit of the doubt. The goal is a welcoming space for uConsole hackers — beginners and veterans alike.

## Scope

This code applies to all project spaces: GitHub issues, pull requests, discussions, the uconsole.cloud dashboard, and any other channels operated by the project. It also applies when representing the project in public.

## Reporting

Report violations to **mike@uconsole.cloud**. Reports will be handled confidentially. Per the Covenant's enforcement guidelines, the maintainer commits to acknowledging reports within 48 hours and taking action proportional to the impact of the behavior.

For the full text of the Contributor Covenant 2.1, including the enforcement ladder, see <https://www.contributor-covenant.org/version/2/1/code_of_conduct/>.
